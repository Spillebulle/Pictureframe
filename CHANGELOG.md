# Changelog

## 1.0.2

- Zooming past 4× shows sharp pixels again instead of a blur.
- The corner button no longer shows while you are picking an element to report.

## 1.0.1

- Shorter extension description, so the Chrome Web Store accepts the package.

## 1.0.0

- Click a plain picture to open it in a fullscreen viewer; links, buttons and site galleries keep their clicks.
- Zoom at the cursor from 5 % to 5000 %, pan, rotate, flip, copy and download.
- Right click works again on sites that block it, and transparent sheets over photos are seen through.
- Canvases, inline SVG and videos open only with Alt + click or the corner button, so spreadsheets and charts behave.
- Report a misfire from the popup: pick the element and paste the copied report into a GitHub issue.
