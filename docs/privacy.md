# Privacy

Pictureframe collects nothing. It has no account, no analytics and no server.

- **Pictures.** When you open, copy or download a picture, Pictureframe fetches that picture from the address the page already uses for it. Nothing is sent anywhere else.
- **Settings.** Your settings are kept with `chrome.storage.sync`, so Chrome may sync them between your own browsers. Pictureframe cannot read them from anywhere but your browser.
- **Misfire reports.** A report is only made when you start one from the popup. It is copied to your clipboard and shown to you. It reaches GitHub only if you paste it into an issue yourself, and you can read and edit every line before you do. The page address in a report has its query string and fragment removed.

Pictureframe runs on every page because a picture can be on any page. It reads a page only to find the picture you click on.

Questions go to the [issue tracker](https://github.com/Spillebulle/Pictureframe/issues).
