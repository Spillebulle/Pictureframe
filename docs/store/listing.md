# Chrome Web Store listing

Everything the Developer Dashboard asks for that the API cannot set. Paste
field by field. Pictures in this folder are regenerated by `shots.py`.

## Store listing tab

**Description**

```
Click any picture on any web page to open it in a fullscreen viewer. Zoom with the scroll wheel around the exact point under your cursor, from 5 % to 5000 %, and drag to pan. Past 4× the picture switches to sharp pixels so you can inspect fine detail.

It stays out of the way. If a picture is a link, a button or part of a site's own gallery, the click goes to the site as usual. Spreadsheets, charts and maps keep their clicks too. To open anything anyway, hold Alt while clicking or use the small button in the picture's corner.

In the viewer:
• Fit to window or view at actual size
• Rotate in 90° steps and flip
• Copy the picture to the clipboard
• Download it, or open it in a new tab
• Keyboard shortcuts for all of it: F, 1, R, H, C, D, Esc

Right click works again on sites that block it, and transparent sheets laid over photos are seen through, so you get the real picture.

If Pictureframe ever opens something it should not, or ignores a picture it should open, choose "Report a misfire" in the toolbar popup and click the thing. You get a report to paste into a GitHub issue.

No account, no analytics, no server. Pictureframe only fetches the picture you ask it to show.

Open source under GPL-3.0: https://github.com/Spillebulle/Pictureframe
```

## Privacy tab

**Single purpose**

```
View any picture on a web page in a fullscreen viewer with zoom, pan, rotate, copy and download.
```

**Permission justifications**

| Permission | Justification |
| :--- | :--- |
| `storage` | Saves the user's settings (on/off, modifier key, zoom speed, hover button) and syncs them between their browsers. |
| `contextMenus` | Adds "Inspect in Pictureframe", "Download with Pictureframe" and "Copy Clean Image Link" to the right click menu on pictures. |
| `downloads` | The viewer's Download button and the right click "Download with Pictureframe" item save the picture the user chose. |
| Host permission `<all_urls>` | A picture can be on any page, so the content script must run on every page to open the one the user clicks. The background worker also fetches the chosen picture's bytes from its own address so it can be copied to the clipboard when the page serves it from another origin. |

**Remote code**: No, I am not using remote code. All JavaScript is in the package.

**Data usage**: tick nothing; it collects none of the listed kinds of data.
Then tick all three certifications (not sold, not used for unrelated
purposes, not used for creditworthiness).

**Privacy policy URL**:
`https://github.com/Spillebulle/Pictureframe/blob/main/docs/privacy.md`
